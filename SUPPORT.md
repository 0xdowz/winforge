# WinForge Support & Community Guidelines

Thank you for using **WinForge**!

## How to Get Support

### 1. Documentation & Guides
Before opening an issue, please review:
- [README.md](README.md): Quick start guide, flags, and CLI reference tables.
- [SECURITY.md](SECURITY.md): Safety model, protected services, and non-destructive defaults.

### 2. Reporting Bugs
If you encounter a bug or unexpected error:
- Search existing [GitHub Issues](https://github.com/0xdowz/winforge/issues) to verify if it has already been reported.
- If not, create a new report using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).

### 3. Proposing Enhancements & Tweaks
If you have suggestions for new diagnostic metrics or system tweaks:
- Open a feature request using the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).

### 4. Security Disclosures
For security vulnerabilities, please refer to [SECURITY.md](SECURITY.md). Do not disclose security issues publicly in open GitHub issues.
