## Capture Guidelines

- **Terminal Environment**: Windows Terminal with `Cascadia Code` font or `JetBrains Mono`.
- **Theme**: Dark mode (One Half Dark, Dracula, or Windows Terminal Default Dark).
- **Window Size**: Minimum 120 columns × 32 rows for readable GitHub rendering.
- **Format**: PNG for static screenshots, GIF for workflow recordings.
